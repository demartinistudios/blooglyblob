# Servo and horn reference photographs

Original project photographs document the Kitronik 25105 servo kit and its disk
horn. They show component identity, face features and hole arrangement. Perspective
prevents using the ruler or caliper display in an image as a precise dimension.

The [servo reference](../servos/README.md#measured-disk-horn) records the separately
measured dimensions, including plate thickness, raised centers, mounting-hole
spacing and seated height. Consult its manufacturer links for the servo case and
spline specification. Measurements of this reference sample are not manufacturing
tolerances or proof of fit for every supplied horn.
