# Assembly requirements

The [build guide](../build-guide/README.md) contains the maintained assembly
instructions. Structured inputs here provide one source for shared engineering
facts:

- [hardware.json](hardware.json): fastener and purchased-hardware allocations.
- [electrical.json](electrical.json): power and signal tables, read directly by
  the guide builder.
- [interfaces.json](interfaces.json): mating relationships and review requirements.

Change these inputs with the affected CAD/print/guide review described in the
[hardware workflow](../README.md). Keep specifications, installed quantities and
physical observations distinct; do not copy the tables into a competing guide.
